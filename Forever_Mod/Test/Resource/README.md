# Test/Resource

`Test`组mod用到的资源文件(`Forever_UE/Resource/Config/config.json`的`resource_paths`已收录这个目录)：

- `test.script`——配合`TestScript`的示例剧情，`control`占位符由C++替换。
- `config_test.json`——`TestScript`剧情的完整`config.json`样例(`story_scripts`只挂`test.script`，`main_story`为`script_empty`)，按需拷成实际的`config.json`使用。

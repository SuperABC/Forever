# MapEditor

地形 + 路网 + 地块的可视化编辑器，导出游戏可直接读取的 `.terrain` / `.roadnet`，用来做**手工设计、确定性**的地图（取代纯随机生成）。单个 HTML + 本地 three.js（r149，`vendor/`），无需联网和构建。

## 打开
用 Chromium 系浏览器（Chrome / Edge）直接打开 `map_editor.html`（`file://` 可用）。有 File System Access API 时可以原地保存，否则退化为下载文件。

## 功能
- **地形**：每个 element(10m) 一个任意字符串（free text，随机稳定颜色区分，可手改）。笔刷：刷地形 / 刷水 / 抬高 / 降低 / 抹平到目标高度 / 平滑。`plain` 是平原：默认高度不让改（建筑和地块只建在高度 0 的平原上），抬高/降低/抹平/平滑笔刷的"**允许改平地**"选项默认勾选(2026-11-21 起)，所以平原格的高度也能改；取消勾选就只改非平原格（被改成高度非 0 的平原不能建）；**水可以放在任意格子**，包括岸边的平原格（否则水面和地面之间会露出缝隙；地面以下有水、岸边地面以上有水都合理，不会警告）。抬高/降低/抹平/平滑有"**限定地形**"开关：打开后按下鼠标时笔刷中心在哪个地形上，这一笔就只改这个地形的格子（平滑时平原/别的地形的邻格仍参与平均，所以山体交界处会被平滑地拉向平原高度，不会越抹越陡）。每种笔刷各自记住半径/强度/目标高度/水位/限定地形，切换笔刷不会互相覆盖。`[` `]` 调当前笔刷的半径。地形工具左侧底部有两个**一键整理**按钮（整张地图，一次可撤销）：**一键平滑高度**——对所有平原的边界，非平原格点的高度按到平原的距离缓降（紧贴平原的一圈接近 0，"缓降宽度"格以外不动；山的抬升、海的下降都朝 0 缓降），消除交界处"三高一低"的格子；**一键平滑类型**——对所有地形类型做众数滤波（每格取 3×3 里占多数的类型），去掉 1 格宽的毛刺和突角，改成平原的格子高度清 0。顶栏的"**水面**"开关(2D 底图的蓝色着色和 3D 水面，只影响显示)、"**等高线**"开关和间距（每 5 条加粗的主等高线）用来看高度和坡度。
- **可建设视图**：地形栏顶部的"可建设视图"开关。打开后 2D 底图不再显示各地形自己的颜色，只分绿(可建设)/红(不可建设)两种底色，再叠加高度渐变(负=偏蓝变暗，正=偏暖变亮)；规则和游戏里的 construction 一致(3×3 邻域高度全为 0，不看地形类型和水)，用笔刷改高度时实时重算。只影响 2D 显示，不改数据，3D 视图不受影响。
- **路网**：直线（起点、终点）、曲线（起点、控制点、终点，二次 Bezier）；道路类型（车道/停车/人行道组合，对应 `default_*` 断面资产）；类别：**平地 / 贴合地形 / 隧道口 / 隧道 / 桥**（隧道口用平地资产但给地形开口，所以不靠高度差猜）。**高度设在节点上而不是路上**：左侧只有一个"高度"字段，表示**下一个新建节点**的高度（起点、终点都用它），按住 **Alt+滚轮**快捷调整（步长 0.5）。头尾高度相同走直线，不同走扁 S 形（两端水平，控制点在 1/3 长度处）。"地形"按钮：打开就取点击处的地形高度；选中节点后右侧"=地形"按钮把它的高度设成地形高度。点在已有节点上沿用节点自己的高度，点在路中间（T 口）取那条路在该处的高度。贴合地形的路按地形每 10m 取一段，头尾节点高度和地形的差值逐渐过渡。贴合段如果某一端的节点连着非贴合的路（隧道口/隧道/平地/桥，它们的端点都是水平的），这一端最后 1/4 路长（`HUG_LEVEL_RATIO`=0.25，两端各自算）会 smoothstep 缓入到节点高度、终点斜率为 0，和后面的平路接上不留折角；另一端仍紧跟地形。桥带桥墩，连续的桥自动归成一条桥墩链。左侧"吸附"板块有四个独立开关（默认全开）：**吸附节点**（点到已有节点）、**吸附道路**（落在路中间自动切分建 T 口）、**吸附边界**（落在地图边界上建**城外连接点**）；与同层的路交叉自动建十字路口（不同高度不建，不受开关影响）。**吸附角度**：起点是已连着道路的节点（或路中间）时，终点（曲线是控制点）在 10° 内吸到特殊角度——直角（垂直于该路，节点和路中间都有）、平角（沿该路延长线继续直走，只有节点上有）；黄色虚线是引导线；节点连了多条路时取最接近鼠标方向的那个；落在节点/城外连接点上时以那个目标为准。点完终点后**自动以终点为起点继续画下一条**（终点是城外连接点则结束），右键/Esc 结束；画的过程中改左侧的类型/车道/名称/高度/画法，立即作用于正在画的这条路。不含铁路、公交、环岛。
- **地块**：依次点两个路口节点（矩形一条边），再移动鼠标拉出深度并点击确认（深度吸附到对面正好有节点的位置）；四个方向的缩进（margin）可在右侧编辑（留空=自动，取临街道路半宽）；选地块类型（住宅/商业/工业/办公 × 高/中/低、测试）。绿化不再是地块类型，见下一条。
- **绿化**：**绿化**工具，"画多边形"模式下依次点顶点，鼠标靠近第一个点（出现绿圈）再点一下闭合成环；**可以是凹多边形，边不能自交**（画的时候会拒绝相交的边）；顶点吸附到路口节点；`Backspace` 撤销最后一点，`Esc`/右键点一下取消。"连接道路"模式：先点绿化区的一条边（变蓝），再点一条路，这条边就"连到"那条路（一条边只连一条路，重复点覆盖；右侧面板可删连接）。没连任何路的绿化只做景观（地址不可导航），连了路的才有行人入口，游戏里会按活动圆到连路边的最短距离把圆接进行人导航。`Alt+左键` 点选绿化，`Delete` 删除。
- **选择**（没有单独的选择工具）：在**路网**工具里按住 **Alt+左键**点选节点/道路，Alt+左键点空白处取消选择，Alt+左键在空白处拖出**框选**选中框内所有节点（右侧可"删除选中节点"或按 `Delete` 批量删除，连着的路和地块一并删，可撤销）；Alt+左键拖节点移动（对齐整数格），拖选中道路的菱形把手调弧度。**地块**工具里 Alt+左键点选地块、点空白取消。**右键拖动平移**，右键点一下（不拖）结束正在画的路/地块。
- **行道树/路灯 tag**：每条路有 `行道树`、`路灯` 两个文本框（路网工具左侧是新建路的默认值，默认都是 `default`；选中路后右侧可改；空=这条路没有）。导出时只给平面（ground）路段写 `treeTag`/`lampTag`，游戏侧 `roadnet_file` 按 tag 选资产（现在只有 `default`，和 checkboard 用同一套），见 `Source/Basic/map/roadnet_file.md`。切分出来的两半继承原来的 tag。
- **双击切路**：在**路网**工具里双击一条地面/贴路爬升路上的一点，在此处新增一个路口，把这条路分成两段（沿用类型/车道/名字，曲线按该点切开保持形状；隧道/桥不能从中间切；已有节点的地方不切）。可撤销。
- **撤销/重做**：`Ctrl+Z` / `Ctrl+Shift+Z`（或 `Ctrl+Y`），上限 80 步；地形按笔画差分。`Ctrl+S` 保存路网。
- **视图**：2D 顶视图（滚轮缩放，空格+左键、中键或右键拖动平移）与 three.js 3D 视图（轨道相机）切换；右侧面板显示属性和校验警告（道路穿过非平原/有水、地块压在不可建设区域(3×3 邻域高度不全为 0，和地形类型无关)等）。

## 文件格式
设计和解析代码在 `Source/Basic/map/terrain_file.md`、`Source/Basic/map/roadnet_file.md`。单位 = element（10m），+Y 向南。
- **`.terrain`**（小端二进制）：魔数 `FTRN`；u32 宽、高；调色板（u16 条数，每条 u16 长度+UTF-8，下标 0 固定 `plain`）；`u16[w*h]` 地形下标；`f32[w*h]` 高度；`f32[w*h]` 水位（NaN=无水）。
- **`.roadnet`**（宽松 JSON）：`{source, output}`。`source` 是编辑器自己的编辑模型（版本 2：节点带高度 `z`，路没有 `height`；打开旧版文件会自动迁移，隧道/桥按旧布局拆成多条路），`output` 是展开后的结果，游戏只读 `output`：`nodes / roads / lots / greens`。路口切分、爬升采样、隧道/桥拆段、桥链 `chain`、地块矩形都在导出时算好。

## 在游戏里使用
`config.json`：
```json
"terrain_mods": [ "terrain_file --path=C:/maps/city.terrain" ],
"roadnet_mods": [ "roadnet_file --path=C:/maps/city.roadnet" ]
```
路径用绝对路径（或相对进程工作目录）。地图尺寸以游戏为准：文件比游戏地图大则裁剪，小则补 plain，并打日志警告。`samples/` 里有一份演示（`demo.terrain`、`demo.roadnet`、`demo_config.json`，配置里是本机绝对路径，换机器要改），可用 `Tools/RoadnetViz` 出图：

```
x64\Release\RoadnetViz.exe Tools\MapEditor\samples\demo_config.json
```

## 开发 / 测试
纯逻辑在 `js/`（`terrain.js`、`roadnet.js`、`lots.js`、`greens.js`、`io.js`，无 DOM，UMD 挂在 `globalThis.ME`），Node 直接测：
```
node tests/test_terrain.js
node tests/test_roadnet.js
node tests/test_lots.js
node tests/test_greens.js
node tests/make_demo.js     # 重新生成 samples/
```

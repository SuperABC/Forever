# MapEditor

地形 + 路网 + 地块的可视化编辑器，导出游戏可直接读取的 `.terrain` / `.roadnet`，用来做**手工设计、确定性**的地图（取代纯随机生成）。单个 HTML + 本地 three.js（r149，`vendor/`），无需联网和构建。

## 打开
用 Chromium 系浏览器（Chrome / Edge）直接打开 `map_editor.html`（`file://` 可用）。有 File System Access API 时可以原地保存，否则退化为下载文件。

## 功能
- **地形**：每个 element(10m) 一个任意字符串（free text，随机稳定颜色区分，可手改；内置的 `terrain_mountain`/`terrain_ocean`/`terrain_river`/`terrain_beach`(沙滩，米黄色，需 `terrain_beach` mod 启用才有材质，游戏里沙滩靠近水面渐变成湿沙)在调色板里有固定颜色）。笔刷：刷地形 / 刷水 / 抬高 / 降低 / 抹平到目标高度 / 平滑。`plain` 是平原：默认高度不让改（高度不一定是 0：抹平出来的任意高度平台也能建），抬高/降低/抹平/平滑笔刷的"**允许改平地**"选项默认勾选(2026-11-21 起)，所以平原格的高度也能改；取消勾选就只改非平原格（被改成高度非 0 的平原不能建）；**水可以放在任意格子**，包括岸边的平原格（否则水面和地面之间会露出缝隙；地面以下有水、岸边地面以上有水都合理，不会警告）。抬高/降低/抹平/平滑有"**限定地形**"开关：打开后按下鼠标时笔刷中心在哪个地形上，这一笔就只改这个地形的格子（平滑时平原/别的地形的邻格仍参与平均，所以山体交界处会被平滑地拉向平原高度，不会越抹越陡）。每种笔刷各自记住半径/强度/目标高度/水位/限定地形，切换笔刷不会互相覆盖。`[` `]` 调当前笔刷的半径。地形工具左侧底部有两个**一键整理**按钮（整张地图，一次可撤销）：**一键平滑高度**——对所有平原的边界，非平原格点的高度按到平原的距离缓降（紧贴平原的一圈接近 0，"缓降宽度"格以外不动；山的抬升、海的下降都朝 0 缓降），消除交界处"三高一低"的格子；**一键平滑类型**——对所有地形类型做众数滤波（每格取 3×3 里占多数的类型），去掉 1 格宽的毛刺和突角，改成平原的格子高度清 0。顶栏的"**水面**"开关(2D 底图的蓝色着色和 3D 水面，只影响显示)、"**等高线**"开关和间距（每 5 条加粗的主等高线）用来看高度和坡度。
- **可建设视图**：地形栏顶部的"可建设视图"开关。打开后 2D 底图不再显示各地形自己的颜色，只分绿(可建设)/红(不可建设)两种底色，再叠加高度渐变(负=偏蓝变暗，正=偏暖变亮)；规则和游戏里的 construction 一致(3×3 邻域高度极差 < `HEIGHT_EPS`=1e-5，高度可以不为 0，不看地形类型和水)，用笔刷改高度时实时重算。只影响 2D 显示，不改数据，3D 视图不受影响。
- **路网**：直线（起点、终点）、曲线（起点、控制点、终点，二次 Bezier）；道路有两个车道字段：**车道资产**（文本，`road.asset`，缺省 `default`，对应游戏里 `Asset/Roadnet/<Asset>/Mesh/<asset>_*`，目前只有 default）和**车道**（下拉，车道类型，是 default 资产的全集：双向2车道(左1右1)/3车道(左1右2)/3车道(左2右1)/双向4车道(左2右2)/单向2车道(左0右2)/单向2车道(左2右0)，括号里是道路在屏幕上从下往上走时左边/右边的车行道数(右侧=起点→终点方向的车道，左侧=终点→起点方向的车道)，由车道类型决定通行方向；导出为 `asset` + `lanes`）。视角放大到路画得够宽(≥16px)时，2D 图上会画**车道标线**：双向路画一条黄线(代表双黄线)，位置在两个行车方向的分界上，两侧车道数不对称时黄线偏向车道少的一侧；单行道沿车行道中线画行车方向箭头；类别：**平地 / 路面贴合地形 / 地形贴合路面 / 隧道口 / 隧道 / 桥**（路面贴合地形=路面高度跟着地形起伏；地形贴合路面=路面高度取节点 z 不变，游戏里把地形削平/填平到路面，编辑器里地形显示不变）（隧道口用平地资产但给地形开口，所以不靠高度差猜）。**高度设在节点上而不是路上**：左侧只有一个"高度"字段，表示**下一个新建节点**的高度（起点、终点都用它），按住 **Alt+滚轮**快捷调整（步长 0.5）。头尾高度相同走直线，不同走扁 S 形（两端水平，控制点在 1/3 长度处）。"地形"按钮：打开就取点击处的地形高度；选中节点后右侧"=地形"按钮把它的高度设成地形高度。点在已有节点上沿用节点自己的高度，点在路中间（T 口）取那条路在该处的高度。贴合地形的路按地形每 10m 取一段，头尾节点高度和地形的差值逐渐过渡。贴合段如果某一端的节点连着非贴合的路（隧道口/隧道/平地/桥，它们的端点都是水平的），这一端最后 1/4 路长（`HUG_LEVEL_RATIO`=0.25，两端各自算）会 smoothstep 缓入到节点高度、终点斜率为 0，和后面的平路接上不留折角；另一端仍紧跟地形。桥带桥墩，连续的桥自动归成一条桥墩链。左侧"吸附"板块有四个独立开关（默认全开）：**吸附节点**（点到已有节点）、**吸附道路**（落在路中间自动切分建 T 口）、**吸附边界**（落在地图边界上建**城外连接点**）；与同层的路交叉自动建十字路口（不同高度不建，不受开关影响）。**吸附角度**：起点是已连着道路的节点（或路中间）时，终点（曲线是控制点）在 10° 内吸到特殊角度——直角（垂直于该路，节点和路中间都有）、平角（沿该路延长线继续直走，只有节点上有）；黄色虚线是引导线；节点连了多条路时取最接近鼠标方向的那个；落在节点/城外连接点上时以那个目标为准。点完终点后**自动以终点为起点继续画下一条**（终点是城外连接点则结束），右键/Esc 结束；画的过程中改左侧的类型/车道/名称/高度/画法，立即作用于正在画的这条路。不含铁路、公交、环岛。
- **地块**：依次点两个路口节点（矩形一条边），再移动鼠标拉出深度并点击确认（深度吸附到对面正好有节点的位置）；四个方向的缩进（margin）可在右侧编辑（留空=自动，取临街道路半宽）；选地块类型（住宅/商业/工业/办公 × 高/中/低、测试）。绿化不再是地块类型，见下一条。
  - **非 0 高度地块(2026-11-23)**：地块高度 z = 两个基准节点 z 的均值（两者差 > `HEIGHT_EPS` 会警告），导出的 `corners` 带第 3 个数 z。把地块放在半山腰/山顶：先用地形"抹平"笔刷把区域抹成同一高度 H（抹平会吸附到目标高度，整块平台逐位相同），再把方框路节点和地块基准节点的高度设成 H（节点"=地形"按钮即可）。**路和地块不同高就不算相邻**：只有水平（两端 z 差 ≤ `HEIGHT_EPS`）且 z 等于地块 z 的平地直路才会成为该边的边界路。地块下的格子必须是可建设区域（见"可建设视图"），否则警告。样例：`samples/plateau.*`（`node tests/make_plateau.js` 生成）。
  - **建地块的强制规则(2026-11-24)**：①前两次点击选的两个节点之间必须正好有一条**直线路**，且是 (a) **平地**路：两端高度相同，并且都等于该处地形高度；或 (b) **地形贴合路面**(`fit`)的路：两端高度相同(不要求等于地形)。其他类型(路面贴合地形/隧道口/隧道/桥)、曲线路、两端不等高、没有路，第二下点击会被拒绝并提示原因，地块建不出来。②满足时地块高度 = 这条路的高度，并且**地块足迹自动抹平到该高度**(足迹=和地块矩形有重叠的每个格子(哪怕只擦到一角)各取 3×3 邻域，因为游戏的可建设判断看 3×3 邻域)，建地块和抹平是一步撤销。右侧改"深度"时同样会把新盖到的格子抹平。③足迹被**锁定**：之后所有地形笔刷(抬高/降低/抹平/平滑，画地形只换类型)和"一键平滑高度/类型"都不会改锁定格的高度；平滑笔刷里锁定格仍参与邻格平均，"一键平滑高度"把锁定格当锚点——它周围的格子朝锁定格自己的高度缓降/缓升(不再是朝 0)。抹平新地块时会避开别的地块的足迹。`AREA_PLACEHOLDER`(占位分区)不受以上约束(不校验、不抹平、不锁定)。拖动节点改位置/改节点高度不会自动重抹，需要的话把深度改一下再改回去，或用抹平笔刷处理。
- **绿化**：**绿化**工具，"画多边形"模式下依次点顶点，鼠标靠近第一个点（出现绿圈）再点一下闭合成环；**可以是凹多边形，边不能自交**（画的时候会拒绝相交的边）；顶点吸附到路口节点；`Backspace` 撤销最后一点，`Esc`/右键点一下取消。"连接道路"模式：先点绿化区的一条边（变蓝），再点一条路，这条边就"连到"那条路（一条边只连一条路，重复点覆盖；右侧面板可删连接）。没连任何路的绿化只做景观（地址不可导航），连了路的才有行人入口，游戏里会按活动圆到连路边的最短距离把圆接进行人导航。`Alt+左键` 点选绿化，`Delete` 删除。
- **绿化区 green id(2026-11-24)**：每个绿化区有一个 `green id` 字符串——绿化工具左侧栏是新画绿化区的默认值，选中绿化区后右侧栏可改。**空=游戏按权重随机选 green mod**（原有逻辑）；填了(如 `green_park`)就用指定的 mod，不走随机；填了但游戏里没注册/没启用，Core 告警并退化成随机。导出为 `output.greens[].id`，旧文件没有这个字段按空处理。
- **选择**（没有单独的选择工具）：在**路网**工具里按住 **Alt+左键**点选节点/道路，Alt+左键点空白处取消选择，Alt+左键在空白处拖出**框选**选中框内所有节点（右侧可"删除选中节点"或按 `Delete` 批量删除，连着的路和地块一并删，可撤销）；Alt+左键拖节点移动（对齐整数格），拖选中道路的菱形把手调弧度。**地块**工具里 Alt+左键点选地块、点空白取消。**右键拖动平移**，右键点一下（不拖）结束正在画的路/地块。 拖拽节点/曲线把手要鼠标离开按下点超过 5 像素才真正开始拖，点一下的微小抖动不会误拖(路网和线路工具都一样)。
- **行道树/路灯 tag**：每条路有 `行道树`、`路灯` 两个文本框（路网工具左侧是新建路的默认值，默认都是 `default`；选中路后右侧可改；空=这条路没有）。左侧两个文本框右边各有一个"**仅贴合路面**"复选框（默认勾选）：勾选时只有类型是平地/贴合地形才有内容，换成隧道口/隧道/桥时框自动置空并禁用，换回平地/贴合地形时复原置空前的内容；取消勾选也会复原，之后可以给任意类型填。只影响左侧新建路的默认值，右侧已有路的两个框不受限制。每个路段（不分类型）都写 `treeTag`/`lampTag`，游戏只看这个、指定放什么就放什么（桥/隧道/隧道口不想要树灯就把对应路的两个框清空；`test.roadnet` 里只有 ground/hug 是 `default`），游戏侧 `roadnet_file` 按 tag 选资产（现在只有 `default`，和 checkboard 用同一套），见 `Source/Basic/map/roadnet_file.md`。切分出来的两半继承原来的 tag。
- **双击切路**：在**路网**工具里双击一条地面/贴路爬升路上的一点，在此处新增一个路口，把这条路分成两段（沿用类型/车道/名字，曲线按该点切开保持形状；隧道/桥不能从中间切；已有节点的地方不切）。可撤销。
- **撤销/重做**：`Ctrl+Z` / `Ctrl+Shift+Z`（或 `Ctrl+Y`），上限 80 步；地形按笔画差分。`Ctrl+S` 保存路网。
- **视图**：2D 顶视图（滚轮缩放，空格+左键、中键或右键拖动平移）与 three.js 3D 视图（轨道相机）切换；右侧面板显示属性和校验警告（道路穿过非平原/有水、地块压在不可建设区域(3×3 邻域高度不平，和地形类型无关)等）。

## 线路（火车铁轨 / 飞机航线）

**线路**工具（顶栏第 5 个标签）手工设计线路：独立线路（火车、飞机，自己的轨道/航线）和路网路线（公交，跑在现成路网上）。编辑器不知道车站的具体接口（位置/数量/方向），所以只存"引用"：实体线路只是几何，车站↔线路之间的缺口由游戏里的 route mod 补（编辑器里画虚线）。左侧顶部三个模式，分开用：

- **独立线路**：画法同路网（起点 →（曲线再点控制点）→ 终点，终点自动成为下一条的起点，右键/`Esc` 结束，`T` 切直线/曲线，`Alt+滚轮` 调下一个节点高度，节点高度可填"地形"）。每个节点有高度，每条连线有类型：平地 / 贴合地形 / 隧道口 / 隧道 / 桥（类型显式决定游戏里的形态）；没有车道字段。吸附：节点、地图边界（在边界上建**城外连接点** extern 节点，画成方块，线路从这里出城/回城；已有的 extern 会吸上去，拖动时只能沿边界滑动，导出带 `extern:true`）、线路中间（自动切开）、角度（直角/平角）。`Alt+左键` 选节点/连线（节点可拖，选中连线的菱形把手可拖），`Delete` 删除。
- **route id**：每条连线有一个 route id = 它所属 route mod 的 id（如 `route_train`、`route_air`），每个 id 按哈希显示一个颜色；没填 id 的连线画红色点线并在导出时跳过。规则：面板里**填了** id 时，可以在空地起头，或从同 id 线路的端点/中间接线（接到别的 id 的线上会被拒绝）；面板里**没填**时，可以在空地起头（新线无 id，之后在右栏补，会同时改同一串线），或从有 id 的线路端点/中间接出，新线自动继承它的 id。
- **独立路线环**：把"预设建筑"和"线路节点"依次点成一个闭环（点击一律追加——**同一个点可以在环里出现多次**（比如车站往返各停一次：`车站→东1→东2→东1→车站→西1…`，只有相邻两项不能是同一个点）；`Enter` / 双击 / 左栏"完成环"按钮完成（首尾自动相连，最后一点点回起点会自动去掉），`Backspace`/右键 或"撤销上一点"撤销，`Esc` 取消整个草稿）。相邻两点若能经**同 id 的实体线路**连通就沿线路画实线，否则（例如预设建筑 → 线路节点）画虚线直线，游戏里由 route mod 用扁 S 曲线补上。环上的点只表示"经过"，**新环全部不停站**；`Alt+左键` 点环选中它（此时鼠标只吸附这个环上的点），点环上的预设/节点 = 选中该点（同一个点出现多次时连点轮换每一次经过，标记上序号写成 `1·4`，往返重叠的线向右侧错开画），右栏勾"停站"（每次经过各自设置）（线路节点不能停站）；点环以外的任何地方取消选择，回到"独立路线环"新建。`Delete` 删除选中的环。
- **路网路线**（公交，2026-11-23）：公交车跑在现成路网上，所以不分实体线路和环，只在路的某一侧点出一串站。左栏选"站点资产"（目前只有 `station_bus`）。点路的一侧 = 在该点的垂足建一个站（站点只吸附路的左/右侧，**不吸附路口和节点**；单行道只能放在有车行道的一侧，点另一侧会自动吸到有车道的一侧；`side0`=沿 a→b 的右手边）；一路点下去，**点回起始站闭合成环**完成一条线（`Enter`/左栏"完成"也行，至少 2 站）；`Backspace`/右键 撤销上一站，`Esc` 取消整个草稿。**实时预览**：鼠标所在路侧点到上一站之间画出公交实际会走的行车路线（受单行道、掉头、外连点不可穿行约束）；从上一站开不到时画红色虚线直线，且此时不能新建下一站/闭合。`Alt+左键` 选站或线：站可改"站点资产"、删除（线不足 2 站整条删）；线可整条删。公交线的车站数据在 `source.transit.roadLines`。
- 导出到 `.roadnet` 的 `output.transit`：`{nodes:[{x,y,z}], conns:[{from,to,ctrl,kind,route}], loops:[{route, items:[{preset:output.presets下标, stop} | {node:transit.nodes下标}]}], roadLines:[{route:"route_bus", stops:[{road:output.roads下标, x, y, side:0|1, station}]}]}`，`source.transit` 是编辑模型。游戏侧 route mod 加 `--skip` 参数后改用这份数据（见各 route mod 的 `.md`）。没有在地图里放成功的预设会被丢弃并出警告；整个环没有任何停站也会出警告。

## 左侧栏宽度

左侧栏右边缘有拖动条，拖动调宽（180~600px，记在浏览器里），双击恢复默认。

## 园区/建筑预设

手动指定游戏里 Assign 的结果：地块工具下选中一个地块 → 右面板"添加预设" → 依次点三下：沿路段起点、沿路段终点（都必须靠近这块地**有路的边**）、进深。端点离角/对边不到 3 会强制吸附到角/对边（和 Core 的拉伸规则一致），其余按 0.5 取整。第一个预设放下后，小路会把地块切成若干子地块，后面的预设只能落在某一块子地块里并吸附它的边和角，不能跨小路。建好后点预设填 id（`zone_` 开头=园区，否则=建筑；留空，或填了但游戏里没注册/没启用，空间照占，游戏都退化成按该地块分区权重随机放一栋建筑；占位分区没有权重，所以只占位）；右键/Esc 取消绘制。

导出到 `.roadnet` 的 `presets[]`，由 roadnet_file 传给 Core，Core 在各 mod 的 Assign 之前先放预设；mod 参数 `--skip` 只跳过该 mod 自己的 Assign，权重填充不受影响。预设在 2D/3D 视图里都有显示。

## 文件格式
设计和解析代码在 `Source/Basic/map/terrain_file.md`、`Source/Basic/map/roadnet_file.md`。单位 = element（10m），+Y 向南。
- **`.terrain`**（小端二进制）：魔数 `FTRN`；u32 宽、高；调色板（u16 条数，每条 u16 长度+UTF-8，下标 0 固定 `plain`）；`u16[w*h]` 地形下标；`f32[w*h]` 高度；`f32[w*h]` 水位（NaN=无水）。
- **`.roadnet`**（宽松 JSON）：`{source, output}`。`source` 是编辑器自己的编辑模型（版本 2：节点带高度 `z`，路没有 `height`；打开旧版文件会自动迁移，隧道/桥按旧布局拆成多条路），`output` 是展开后的结果，游戏只读 `output`：`nodes / roads / lots / greens / presets / transit`。路口切分、爬升采样、隧道/桥拆段、桥链 `chain`、地块矩形都在导出时算好。

## 在游戏里使用
`config.json`：
```json
"terrain_mods": [ "terrain_file --path=C:/maps/city.terrain" ],
"roadnet_mods": [ "roadnet_file --path=C:/maps/city.roadnet" ]
```
路径用绝对路径（或相对进程工作目录）。地图尺寸以游戏为准：文件比游戏地图大则裁剪，小则补 plain，并打日志警告。`samples/` 里有一份演示（`demo.terrain`、`demo.roadnet`、`demo_config.json`，配置里是本机绝对路径，换机器要改），可用 `Tools/RoadnetViz` 出图：

```
x64\Release\RoadnetViz.exe Tools\MapEditor\samples\demo_config.json
```

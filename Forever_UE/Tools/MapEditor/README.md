# MapEditor

地形 + 路网 + 地块的可视化编辑器，导出游戏可直接读取的 `.terrain` / `.roadnet`，用来做**手工设计、确定性**的地图（取代纯随机生成）。单个 HTML + 本地 three.js（r149，`vendor/`），无需联网和构建。

## 打开
用 Chromium 系浏览器（Chrome / Edge）直接打开 `map_editor.html`（`file://` 可用）。有 File System Access API 时可以原地保存，否则退化为下载文件。

## 功能
- **地形**：每个 element(10m) 一个任意字符串（free text，随机稳定颜色区分，可手改）。笔刷：刷地形 / 刷水 / 抬高 / 降低 / 抹平到目标高度 / 平滑。`plain` 是平原：高度锁 0（建筑和地块只建在平原上）；**水可以放在任意格子**，包括岸边的平原格（否则水面和地面之间会露出缝隙；地面以下有水、岸边地面以上有水都合理，不会警告）。抬高/降低/抹平/平滑有"**限定地形**"开关：打开后按下鼠标时笔刷中心在哪个地形上，这一笔就只改这个地形的格子（平滑也只参考同地形的邻格）。`[` `]` 调笔刷半径。顶栏的"**等高线**"开关和间距（每 5 条加粗的主等高线）用来看高度和坡度。
- **路网**：直线（起点、终点）、曲线（起点、控制点、终点，二次 Bezier）；道路类型（车道/停车/人行道组合，对应 `default_*` 断面资产）；类别：**平地 / 贴合地形 / 隧道口 / 隧道 / 桥**（隧道口用平地资产但给地形开口，所以不靠高度差猜）。**高度设在节点上而不是路上**：画路前先设"头高度"，点第一下建起点；再设"尾高度"，点第二下建终点。头尾高度相同走直线，不同走扁 S 形（两端水平，控制点在 1/3 长度处）。头/尾高度各有一个"地形"按钮：打开就取点击处的地形高度；选中节点后右侧"=地形"按钮把它的高度设成地形高度。点在已有节点上沿用节点自己的高度，点在路中间（T 口）取那条路在该处的高度。贴合地形的路按地形每 10m 取一段，头尾节点高度和地形的差值逐渐过渡。桥带桥墩，连续的桥自动归成一条桥墩链。可吸附到已有节点（开关）；终点落在路中间自动切分建 T 口，与同层的路交叉自动建十字路口（不同高度不建）；落在地图边界上建**城外连接点**。**吸附直角**（默认开）：起点是已连着道路的节点（或路中间）时，终点（曲线是控制点）在 10° 内吸到垂直于该路的方向，黄色虚线是引导线；节点连了多条路时取最接近鼠标方向的那条的垂线；落在节点/城外连接点上时以那个目标为准。不含铁路、公交、环岛。
- **地块**：依次点两个路口节点（矩形一条边），再移动鼠标拉出深度并点击确认（深度吸附到对面正好有节点的位置）；四个方向的缩进（margin）可在右侧编辑（留空=自动，取临街道路半宽）；选地块类型（住宅/商业/工业/办公 × 高/中/低、绿化、测试）。
- **选择**：点选节点/道路/地块；拖节点移动，拖选中道路的菱形把手调弧度；Alt 拖节点对齐整数格；`Delete` 删除。
- **撤销/重做**：`Ctrl+Z` / `Ctrl+Shift+Z`（或 `Ctrl+Y`），上限 80 步；地形按笔画差分。`Ctrl+S` 保存路网。
- **视图**：2D 顶视图（滚轮缩放，空格+左键、中键或右键拖动平移）与 three.js 3D 视图（轨道相机）切换；右侧面板显示属性和校验警告（道路穿过非平原/有水、地块压在非 construction 区域等）。

## 文件格式
设计和解析代码在 `Source/Basic/map/terrain_file.md`、`Source/Basic/map/roadnet_file.md`。单位 = element（10m），+Y 向南。
- **`.terrain`**（小端二进制）：魔数 `FTRN`；u32 宽、高；调色板（u16 条数，每条 u16 长度+UTF-8，下标 0 固定 `plain`）；`u16[w*h]` 地形下标；`f32[w*h]` 高度；`f32[w*h]` 水位（NaN=无水）。
- **`.roadnet`**（宽松 JSON）：`{source, output}`。`source` 是编辑器自己的编辑模型（版本 2：节点带高度 `z`，路没有 `height`；打开旧版文件会自动迁移，隧道/桥按旧布局拆成多条路），`output` 是展开后的结果，游戏只读 `output`：`nodes / roads / lots`。路口切分、爬升采样、隧道/桥拆段、桥链 `chain`、地块矩形都在导出时算好。

## 在游戏里使用
`config.json`：
```json
"terrain_mods": [ "terrain_file --path=C:/maps/city.terrain" ],
"roadnet_mods": [ "roadnet_file --path=C:/maps/city.roadnet" ]
```
路径用绝对路径（或相对进程工作目录）。地图尺寸以游戏为准：文件比游戏地图大则裁剪，小则补 plain，并打日志警告。`samples/` 里有一份演示（`demo.terrain`、`demo.roadnet`、`demo_config.json`，配置里是本机绝对路径，换机器要改），可用 `Tools/RoadnetViz` 出图：

```
x64\Release\RoadnetViz.exe Tools\MapEditor\samples\demo_config.json
```

## 开发 / 测试
纯逻辑在 `js/`（`terrain.js`、`roadnet.js`、`lots.js`、`io.js`，无 DOM，UMD 挂在 `globalThis.ME`），Node 直接测：
```
node tests/test_terrain.js
node tests/test_roadnet.js
node tests/test_lots.js
node tests/make_demo.js     # 重新生成 samples/
```

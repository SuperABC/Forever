# report.h / report.cpp

## 职责
EconSim的报表：城市生成结果，以及政府/个人/组织/外部四类账户在开局和每个月的收入、支出、结余与余额分布。同时写到标准输出和报表文件。

## 关键设计
- **收入/支出明细**来自`Ledger`的累计流水（`Flow`类别×付款方类×收款方类，随社会段存档）。每期用期初/期末两次快照相减，不需要在业务代码里另外记账。账户类别内部的往来（比如私人房东收个人房租）会同时计入该类的收入和支出，所以"结余"看的是净值。
- **分布**：个人存款和组织资金按金额分桶，用`█`画成柱状图，另给分位数。穷/富的参照是开局人均5000元：不足一半(2500元)算穷人，不低于两倍(1万元)算富人，并给出最富10%持有存款的比例。
- **开局时间**：报告模式强制把开局设为人口当前年份的1月1日，按真实日历（含闰年）逐日推进，保证每次运行可公平对比。月度分红在下月1日结算，计入下一个月。
- 城市生成结果包含市民构成（未成年<18、成年18-59、老年>=60）、各类园区/建筑/房间数及政府拥有数、组织、岗位、户。

## 依赖关系
- 依赖：`Map`/`Populace`/`Society`/`Industry`、`Ledger`。
- 被谁依赖：`main.cpp`的`RunReport`（命令行：`EconSim config.json <地图尺寸> <月数> report [报表文件]`）。
